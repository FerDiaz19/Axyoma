🎯 INSTRUCCIONES SÚPER SIMPLES PARA NUEVA LAPTOP
===============================================

Para alguien que quiere configurar exactamente el mismo sistema:

## 📥 PASO 1: DESCARGAR
```bash
git clone https://github.com/FerDiaz19/Axyoma.git
cd Axyoma/Backend
```

## ⚡ PASO 2: EJECUTAR UN SOLO COMANDO

### Si tienes Windows:
```bash
configurar_nueva_laptop.bat
```

### Si tienes Linux/Mac:
```bash
python configurar_nueva_laptop.py
```

## 🎉 ¡YA ESTÁ!

Después de ejecutar ese comando tendrás:
- ✅ Sistema 100% idéntico al tuyo
- ✅ 41 empleados en 2 empresas
- ✅ Login: superadmin / admin123
- ✅ Todo funcionando automáticamente

## 🚀 INICIAR SISTEMA
```bash
python manage.py runserver
```

## 🌐 ACCEDER
http://localhost:8000
